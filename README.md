# 胶片日期水印

一个面向 Windows 的桌面工具，用来批量为 JPG/JPEG 照片添加胶片机、傻瓜相机和早期数码相机风格的日期戳水印。

适合旅行记录、家庭相册、儿童成长照片、纪念日照片，以及任何希望快速做出复古时间戳效果的图片整理场景。

## 项目亮点

- 批量处理多个 JPG/JPEG 文件
- 支持递归扫描整个文件夹
- 默认优先使用 EXIF 拍摄日期
- 支持统一指定日期批量覆盖
- 支持 EXIF 缺失时回退到文件修改日期
- 支持实时预览当前水印效果
- 支持保存和加载设置方案
- 支持自定义字体、颜色、透明度和边距比例
- 支持第二行扩展文案
- 自动输出处理报告，方便核对结果

## 适用场景

- 给旅行照片统一加上胶片日期戳
- 给宝宝照片生成“几岁几个月”的成长记录
- 给纪念日照片生成“相识多久”“结婚多久”之类的第二行信息
- 为缺少原始拍摄日期的旧照片快速补齐视觉化时间标记
- 批量整理适合社交平台发布的复古风图片

## 快速开始

### 环境要求

- Windows
- Python 3

### 安装依赖

```bash
python -m pip install -r requirements.txt
```

### 启动程序

```bash
python app.py
```

### 基本使用流程

1. 选择多张 JPG/JPEG 图片，或选择一个包含图片的文件夹
2. 设置日期来源
3. 调整日期格式、字体、颜色、透明度和边距
4. 按需启用第二行模式
5. 通过预览确认效果
6. 点击“开始处理”
7. 在输出目录查看结果和处理报告

## 功能说明

### 日期来源

程序支持两种日期来源：

- `EXIF`：优先读取照片原始拍摄时间
- `统一指定日期`：为本次处理的所有照片使用同一个日期

如果启用了“缺少 EXIF 时改用文件修改日期”，当图片没有可用 EXIF 信息时，程序会自动使用文件修改时间继续生成水印，而不是直接判定失败。

### 水印样式

主日期水印支持以下配置：

- 日期格式：`yy mm dd` 或 `yyyy.mm.dd`
- 前缀和后缀文本
- 自定义字体文件
- 自定义颜色
- 自定义透明度
- 自定义字体比例
- 自定义右边距与下边距比例

水印默认绘制在图片右下角，并根据图片尺寸自动计算字号和位置，尽量保持不同分辨率下的视觉一致性。

### 第二行模式

除了主日期行，工具还支持第二行附加信息，用来增强“照片故事感”。

可选模式包括：

- `关闭`
- `纪念日`
- `生日`
- `自定义`

其中：

- 纪念日模式可生成类似“在一起 2年3个月5天”的内容
- 生日模式可生成类似“2岁4个月”的内容
- 自定义模式可直接填写任意一句文字

程序会根据文本内容自动选择合适字体，尽量兼顾数字和中文显示效果。

### 预览与批处理

界面支持先选图、先调样式、再批处理的工作流：

- 选择多张图片后可以逐张切换预览
- 修改配置后会实时刷新预览结果
- 批处理完成后会统计成功数、失败数和 EXIF 缺失数量

## 输出结果

处理结果会自动分类到两个目录：

- `dated_output`：处理成功的图片
- `dated_failed`：处理失败的图片副本

同时会生成：

- `dated_output/process_report.csv`

报告中会记录每张图片的来源路径、处理状态、日期来源、失败原因和输出路径，便于后续排查。

## 技术栈

这个项目是一个基于 Python 的桌面应用，主要依赖如下：

- `PySide6`：构建 Windows 桌面界面
- `Pillow`：图像读取、渲染和保存
- `piexif`：读取与保留 EXIF 信息
- `fonttools`：检测字体字符覆盖范围
- `pytest`：测试
- `PyInstaller`：打包为可分发程序

│  ├─image_preview.py          # 预览图生成
│  ├─models.py                 # 配置模型与数据结构

## 测试与打包

### 运行测试

项目包含核心处理流程、预览、配置读写、打包文件检查和水印渲染相关测试。

```bash
pytest
```

如果你的系统里存在多个 Python 环境，也可以使用：

```bash
py -m pytest
```

### 打包

项目提供了 PowerShell 打包脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

如果需要，也可以结合 `app.spec` 或 `film-date-watermark.spec` 自定义 PyInstaller 打包行为。

## 设计目标

这个项目的目标不是做一个复杂的修图软件，而是提供一个开箱即用的“小而准”工具：

- 操作简单，不需要图像处理经验
- 效果统一，适合批量处理
- 可调参数足够多，能兼顾个性化
- 保持 Windows 桌面工具的直接体验
